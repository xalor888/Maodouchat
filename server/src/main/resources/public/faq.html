账户与登录

如何注册毛豆聊天账号？
下载并打开 App，使用手机号注册并验证短信验证码即可。注册过程在设备本地生成加密密钥对，私钥永不离开设备。
忘记密码或无法登录怎么办？
毛豆聊天采用端到端加密，服务端无法重置你的加密密钥。若开启了应用锁 PIN，可使用绑定的恢复方式；若设备丢失，新设备登录后需重新建立会话。建议提前在「设置 -> 账号」备份恢复码。
如何注销账号？
在「设置 -> 账号 -> 注销账号」中提交注销。注销后你的资料、密钥与服务端密文信封将被删除，且不可恢复。详见隐私政策。

聊天与群组

群聊最多支持多少人？
毛豆聊天群聊支持万级成员。群消息采用 Sender Key 群加密协议，在大群中仍保持端到端加密与良好性能。
支持哪些消息类型？
文本、Markdown、图片、视频、语音、文件、投票、骰子、幸运签、表情猜词、位置、联系人、内联键盘等。所有附件均端到端加密（AES-256-GCM）。
如何邀请好友进群？
在群设置中生成群邀请链接分享即可；也可直接在好友聊天中转发邀请。群管理员可设置邀请链接的有效期与使用次数。

隐私与安全

什么是端到端加密？
端到端加密意味着消息在发送方设备加密、接收方设备解密，服务端只看到密文信封。毛豆聊天 1:1 使用 Double Ratchet，群使用 Sender Key，附件 AES-256-GCM。详见安全详解。
服务端能看到我的消息吗？
不能。服务端仅存储密文信封与路由元数据（发送/接收方 ID、时间戳），无法解密消息正文或附件。详见透明度说明。
如何验证对方身份（安全代码）？
在聊天详情中查看「安全代码 / Safety Number」，与对方线下比对。若代码一致，说明会话未被中间人篡改。密钥变更时代码会更新并提示。

密聊

密聊模式与普通聊天有何不同？
密聊模式开启 FLAG_SECURE 防止系统截屏/录屏，界面叠加不可见盲水印（含用户 ID 与时间），并支持频域 DCT-QIM 盲水印供后台取证。可配合阅后即焚让消息定时消失。
密聊的盲水印有什么用？
当有人尝试对密聊内容拍照外泄，可见/不可见水印可用于追溯泄露源（含用户 ID 与时间）。频域盲水印对裁剪、压缩、重拍照有较好鲁棒性，可供后台取证。
阅后即焚如何工作？
单聊可设置 30 秒至 30 天多档计时，消息到时自动从双方设备与服务端删除。截屏会触发对端告警，阅后即焚图片支持一次性查看。

AI

AI 助手会读取我的消息吗？
AI 能力（摘要、翻译、改写、转录、图片分析、语义搜索）为可选功能，需主动触发。开启后相关内容会在加密通道外临时处理以提供能力。你可在设置中随时关闭。
支持哪些 AI 能力？
智能摘要、实时翻译（100+ 语种）、AI 改写、语音转录、图片分析、语义搜索、群聊助手。可通过 Bot API（getAiFeatureFlags 等）查询开关状态。

机器人开发

如何创建机器人？
在 App「设置 -> 我的机器人」创建 Bot 获取 Token，通过 HTTP API 发送消息、管理群组、处理回调。支持 Webhook（HMAC 签名校验）与长轮询两种模式。详见开发者控制台。
Bot API 支持哪些功能？
发送文本/Markdown 消息、内联键盘、图片/文件、位置、联系人；管理群成员与权限；投票；Webhook HMAC 校验；AI 能力开关查询等。完整文档见 开发者控制台。
机器人收费吗？
机器人平台核心 API 免费。若使用官方托管的 AI 能力，可能根据用量计费；自托管服务端则完全免费。

故障排除

消息发送失败 / 收不到消息？
请检查网络连接；确认对方未屏蔽你；查看 App 内连接状态。若使用自托管服务端，检查服务端与推送（FCM）配置。仍有问题请报告问题。
通话质量差怎么办？
音视频通话基于 WebRTC 端到端加密。请切换到稳定网络（Wi-Fi 或 4G/5G），关闭占用带宽的应用。弱网下 App 会自适应降低码率。
如何反馈建议或报告 Bug？
通过 App 内「设置 -> 反馈」提交，或邮件至 support@maodouchat.com。安全漏洞请报告至 security@maodouchat.com。详见帮助中心。

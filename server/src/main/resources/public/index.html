核心功能

每一个功能都经过精心打磨，只为给你最舒适的聊天体验

🔒

端到端加密

Signal Protocol 级别加密，1:1 Double Ratchet + 群 Sender Key。附件 AES-256-GCM，服务端不可读明文。

🤖

AI 助手

智能摘要、翻译、改写、语音转录、图片分析、语义搜索。AI 能力全面赋能你的沟通体验。

📎

附件加密

所有文件传输均经过端到端加密，支持图片、视频、文档、语音等多媒体安全传输。

👥

群聊管理

投票、骰子、幸运签、表情猜词等丰富群玩法。群管理员权限体系，群邀请链接，@提及。

📞

音视频通话

WebRTC 端到端加密音视频通话，支持一对一和群组通话，低延迟高质量。

📱

动态朋友圈

分享生活点滴，支持图文动态、评论互动、点赞。隐私可控的社交空间。

🕵️

密聊模式

FLAG_SECURE 防截图/录屏，可见盲水印含用户 ID 与时间，频域盲水印可供后台取证。

🔥

阅后即焚

单聊 30 秒至 30 天多档计时，截屏告警，支持阅后即焚图片。消息自动消失不留痕迹。

🧨

截屏即焚

密聊检测到截屏/录屏尝试时立即焚毁本地解密缓存媒体，截图无内容可取。

⏳

会话自动销毁

密聊会话超过无活动 TTL 即整体销毁，消息级阅后即焚之外的会话级兜底。

📮

转发白名单

密聊消息仅可转发到白名单会话，白名单外一律拦截，防二次泄密。

📶

SIM 变更防护

SIM 卡被拔出或更换时立即锁定并清除密聊数据，设备易主也不泄密。

🔐

双因素门禁

进入密聊前需二次验证，生物识别/App 锁开道，验证窗口内免重复。

🛡️

新设备风控

仅信任已登记的设备指纹，陌生新设备上的密聊默认锁定不预览。

✅

设备核验

进入密聊前核对对端设备指纹，指纹不一致拒绝展示内容，防中间人。

💬

双向密聊提示

仅当双方都开启密聊时才展示防护徽标，单边密聊明确提示"仅本机防护"。

开放机器人平台

轻松创建和管理你的 Telegram 风格机器人

几行代码，接入机器人

在 App「设置 → 我的机器人」创建 Bot，获取 Token 后即可通过 HTTP API 发送消息、管理群组、处理回调。支持 Webhook 和长轮询两种模式。

Markdown 消息 内联键盘 Webhook HMAC 群管/投票 位置/联系人 密聊 typing 门控 (typtz) 密聊 read-receipt 门控 (redz) 密聊 presence 门控 (presz) 密聊 last-seen 门控 (lastsz)
打开开发者控制台
curl 示例 
# 发送 Markdown 消息
curl -X POST /api/bot/sendMessage \
  -H "X-Bot-Token: YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "chatId": "group_123",
    "text": "**Hello** from _Bot_!",
    "parseMode": "MARKDOWN"
  }'

# 创建内联键盘
curl -X POST /api/bot/sendMessage \
  -H "X-Bot-Token: YOUR_TOKEN" \
  -d '{
    "chatId": "user_456",
    "text": "选择操作：",
    "replyMarkup": {
      "inlineKeyboard": [[
        {"text": "👍 赞", "callbackData": "like"},
        {"text": "👎 踩", "callbackData": "dislike"}
      ]]
    }
  }'

# 查询 Bot 资料
curl /api/bot/me \
  -H "X-Bot-Token: YOUR_TOKEN"

常见问题

关于隐私、安全与使用，你最关心的几个问题

什么是端到端加密？
端到端加密（E2EE）意味着消息在你设备上加密后发出，只有接收方的设备能解密。毛豆聊天采用 Signal Protocol（1:1 Double Ratchet + 群 Sender Key），附件使用 AES-256-GCM，服务端只存储密文信封，无法读取明文。
毛豆聊天免费吗？
毛豆聊天核心功能完全免费，包括端到端加密、群聊、AI 助手与机器人平台。你可以自托管服务端（参见 docs/docker-deployment.md），也可以使用官方托管服务。
支持哪些平台？
Android 客户端现已可用；iOS 与桌面端（Windows / macOS / Linux）正在规划中。服务端为跨平台 Kotlin 后端，可自部署。
密聊模式是什么？
密聊模式开启 FLAG_SECURE 防止系统截屏与录屏，界面叠加不可见盲水印（含用户 ID 与时间），并支持频域 DCT-QIM 盲水印供后台取证。结合阅后即焚，消息可定时自动消失。
如何接入机器人？
在 App「设置 → 我的机器人」创建 Bot 获取 Token，即可通过 HTTP API（Webhook 或长轮询）发送消息、管理群组、处理回调。详见开发者控制台。
我的消息安全吗？
安全。所有 1:1 与群消息默认端到端加密，附件在传输与存储中均为密文。服务端看不到消息正文、附件明文或密钥。详见安全详解。

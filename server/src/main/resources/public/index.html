密聊模式

FLAG_SECURE 防截屏，不可见盲水印含用户 ID 与时间，支持频域取证。

阅后即焚

30 秒到 30 天多档计时，截屏告警，图片支持一次性查看。

截屏即焚

检测到截屏或录屏尝试时，立即销毁本地解密缓存媒体。

会话自动销毁

密聊超过无活动 TTL 即整体销毁，消息级之外再加会话级兜底。

转发白名单

密聊消息只可转发到白名单会话，白名单外一律拦截。

SIM 变更防护

SIM 卡拔出或更换时立即锁定并清除密聊数据，设备易主也不泄密。

双因素门禁

生物识别或 App 锁开道，进入密聊前二次验证。

新设备风控

设备核验

双向密聊提示

双方都开启密聊才展示防护徽标，单边密聊明确提示仅本机防护。

常见问题

你最关心的几个问题

关于隐私、安全与使用，这里先给你明确答案。

什么是端到端加密？
消息在发送设备上加密后发出，只有接收方设备能解密。毛豆聊天采用 Signal Protocol，附件使用 AES-256-GCM，服务端只存储密文信封。
毛豆聊天免费吗？
核心功能完全免费，包括端到端加密、群聊、AI 助手与机器人平台。你也可以自托管服务端。
支持哪些平台？
Android 客户端现已可用；iOS 与桌面端正在规划中。服务端是跨平台 Kotlin 后端，可自行部署。
密聊模式是什么？
密聊开启 FLAG_SECURE 防截屏，叠加不可见盲水印，支持 DCT-QIM 频域取证；结合阅后即焚，消息可定时消失。
如何接入机器人？
在 App「设置 → 我的机器人」创建 Bot 获取 Token，通过 HTTP API 发送消息、管理群组、处理回调。详见开发者控制台。
我的消息安全吗？
安全。所有 1:1 与群消息默认端到端加密，服务端看不到消息正文、附件明文或密钥。详见安全详解。

服务说明

毛豆聊天（Maodouchat）是一款端到端加密的即时通讯应用，提供文本/语音/视频聊天、群组、AI 助手与开放机器人平台。服务包括官方托管服务与可自托管的社区版（参见 docs/docker-deployment.md）。

本条款适用于官方托管服务。自托管实例由其运营方另行规定条款。

账户注册与责任

  • 你需使用真实有效的手机号注册，并对账号活动负责。
  • 你须年满 16 周岁；未成年人应在监护人指导下使用。
  • 妥善保管你的设备、PIN 锁与恢复码。因端到端加密，我们无法帮你恢复加密消息的访问。
  • 不得转让、出租或出售账号。

可接受使用

你不得利用服务从事以下行为：

  • 发送垃圾信息、钓鱼、欺诈或违法内容；
  • 侵犯他人知识产权、隐私或人格权；
  • 分发恶意软件、病毒或进行未授权访问；
  • 骚扰、威胁、仇恨言论或煽动暴力；
  • 对服务进行逆向工程、滥用 API、规避速率限制或破坏服务稳定性；
  • 违反你所在司法管辖区的法律。

违反上述规定可能导致内容删除、账号暂停或终止，并保留追究法律责任的权利。

内容与版权

你保留对所发送内容的全部权利。由于端到端加密，我们无法访问你的消息明文。若你公开发布内容（如动态朋友圈），你需确保拥有相应权利或授权。

若认为你的版权被侵犯，请向 maodouservice@163.com 提交侵权通知，我们将在合理时间内处理。

机器人开发者责任

通过机器人平台开发的 Bot 由其开发者独立运营。开发者须：

  • 对其 Bot 的行为与发送的内容负全部责任；
  • 遵守可接受使用条款与相关法律；
  • 在收集用户数据前获得明确同意；
  • 对 Webhook 端点实施 HMAC 签名校验，防止伪造请求。

我们对第三方 Bot 的行为不承担责任，但保留对违规 Bot 限制访问的权利。

端到端加密的限制说明

重要提示
端到端加密保护消息在传输与存储中的机密性，但不限制接收方的本地行为。
  • 接收方可截图/拍照：加密无法阻止接收方对其设备屏幕截图或拍照。密聊模式可降低此风险（FLAG_SECURE + 盲水印 + 截屏告警），但无法完全消除。
  • 元数据可见：服务端可见发送/接收方 ID 与时间戳等路由元数据，但不可见消息内容。
  • 设备安全：若你的设备被恶意软件感染或未设锁屏，加密保护可能被绕过。请开启应用锁、PIN 锁与系统锁屏。
  • 密钥丢失：私钥仅存于设备。若设备丢失且无备份，历史加密消息无法恢复。

免责声明

服务按「现状」提供，不提供任何明示或默示担保。在法律允许的最大范围内，我们对因使用或无法使用服务造成的间接、附带或后果性损失不承担责任。

服务变更与终止

我们可能不时更新、变更或停止服务的部分功能，并将提前合理通知。你可随时注销账号终止使用。若你严重违反本条款，我们可暂停或终止你的账号。

争议解决

因本条款或服务产生的争议，双方应首先通过协商解决。协商不成的，提交服务运营方所在地有管辖权的人民法院诉讼解决。本条款的解释与适用以中华人民共和国法律为准据法（自托管实例以其运营方约定为准）。

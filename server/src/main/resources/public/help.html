快速入门

  1. 下载安装：从下载页获取 Android APK（iOS / 桌面端规划中）。
  2. 注册账号：使用手机号注册并验证短信验证码。注册过程在设备本地生成加密密钥对。
  3. 完善资料：设置昵称与头像。
  4. 添加好友：通过手机号、用户名或通讯录匹配（可选）添加好友。
  5. 开始聊天：所有 1:1 与群消息默认端到端加密。
  6. 开启应用锁：在「设置 -> 隐私」开启应用锁与 PIN，保护账号安全。

账号与登录问题

收不到短信验证码？

请确认手机号正确、信号正常、未开启拦截。若长时间未收到，可等待 60 秒后重新发送。仍不行请联系运营商或换号尝试。

忘记 PIN / 应用锁？

应用锁 PIN 用于本地验证。若遗忘，可在登录界面使用绑定的恢复方式重置；重置后部分本地加密数据需重新同步。建议在「设置 -> 账号」提前备份恢复码。

更换设备？

在新设备登录后，会重新建立加密会话。由于端到端加密，旧设备上的历史消息无法自动迁移到新设备（除非你已开启多设备同步并验证）。

聊天功能

消息发不出去？

  • 检查网络连接（Wi-Fi / 移动数据）；
  • 确认对方未屏蔽你；
  • 查看 App 顶部连接状态指示；
  • 若使用自托管服务端，检查服务端与推送配置。

如何发起密聊？

在聊天详情中开启「密聊模式」，将启用 FLAG_SECURE 防截屏、盲水印与阅后即焚。详见安全详解。

如何创建群聊？

在聊天列表点击新建群组，选择成员即可。群聊支持万级成员，采用 Sender Key 群加密。管理员可在群设置中管理权限与邀请链接。

通话问题

通话质量差 / 卡顿？

  • 切换到稳定网络（Wi-Fi 或 4G/5G）；
  • 关闭占用带宽的后台应用；
  • 弱网下 App 会自适应降低码率；
  • 视频通话可临时关闭视频保留语音。

音视频通话基于 WebRTC 端到端加密，通话内容不被服务端可见。

报告问题

遇到 Bug 或异常行为？请按以下流程报告，帮助我们快速定位：

  1. 复现：记录触发问题的具体操作步骤。
  2. 收集信息：App 版本（设置 -> 关于）、系统版本、网络环境、错误提示截图。
  3. 选择渠道：
    • App 内：「设置 -> 反馈」直接提交（推荐，含诊断信息）；
    • 邮件：support@maodouchat.com。
  4. 安全漏洞：请勿公开，单独邮件至 security@maodouchat.com，并给我们合理修复时间。

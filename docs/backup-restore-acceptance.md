# 备份恢复验收清单

## 1. 备份脚本

**脚本**：`scripts/backup-production.sh`

### 备份内容

| # | 内容 | 检查 | 通过 |
|---|------|------|------|
| 1 | PostgreSQL 全量转储（`pg_dump`） | [ ] |

| # | 检查 | 通过 |
|---|------|------|
